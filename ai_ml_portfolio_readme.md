### 2. RAG Knowledge Assistant

**Objective:** Build a document question-answering application using retrieval-augmented generation.

**Pipeline:**

```text
Documents
   ↓
Document Loading
   ↓
Text Splitting / Chunking
   ↓
Embeddings
   ↓
Vector Store
   ↓
Similarity Retrieval
   ↓
Prompt Construction
   ↓
LLM Response
```

**Areas explored:**

- Document ingestion
- Chunking strategies
- Embeddings
- Vector similarity search
- Retrieval quality
- Context construction
- Grounded responses
- Failure analysis: retrieval versus generation

**Technology:** Python, FAISS, embeddings, Ollama, RAG

---

### 3. ReAct Agent and Tool Calling

**Objective:** Understand how an agent reasons through a task, selects tools, observes results, and produces a final response.

**Capabilities explored:**

- Tool registry
- Calculator and weather tools
- Maximum execution steps
- Agent memory
- Logging of thoughts, actions, and results
- Streaming-style execution visibility
- Tool input and output handling
- Error handling and bounded execution

**Conceptual flow:**

```text
User Question
   ↓
Agent Reasoning
   ↓
Tool Selection
   ↓
Tool Execution
   ↓
Observation
   ↓
Additional Reasoning
   ↓
Final Answer
```
